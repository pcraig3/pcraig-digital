# PCRAIG DIGITAL

Website for PCRAIG DIGITAL INC.

Static HTML/CSS site intended for deployment on GitHub Pages.

## Local development

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Deployment

The production site will be hosted using GitHub Pages.
